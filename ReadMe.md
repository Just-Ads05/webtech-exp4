# 🚀 Project Setup Guide

Follow these steps to get both the frontend and backend up and running.

---

## Front End

Navigate to the frontend directory, install dependencies, and start the development server:

```bash
cd techfest-react
npm install
npm run dev
```
##  Back End
```bash
cd techfest-backend
(Add .env file here in folders)
npm init -y
npm install express dotenv mongoose bcrypt jsonwebtoken cors ejs
node server.js
